# pondex 使い方

## 音源の登録と編集

「音源を追加…」またはファイルのドラッグ＆ドロップで音声を登録します。対応形式はWAV、MP3、Ogg Vorbis、Ogg Opus、FLAC、AIFF、M4A、AAC、WMAです。Media Foundationを使う形式はPC側の対応状況に依存します。

音源カードでは、名前、キー、Group、音量、Pan、Pitch、Loop、Fade In／Fade Out、メモを設定できます。

- 音量は通常0～100%です。音源の「速度・音程の調整…」で限界突破を許可すると、その音源だけ200%まで調整できます。
- カード幅が狭い場合、一時停止ボタンは「休止」と表示されます。機能は同じです。
- 「詳細」→「参照…」で、設定を保ったまま音声ファイルだけを差し替えられます。
- 「この音源を削除…」はプロジェクトから登録を外すだけで、元ファイルは削除しません。
- 「操作」→「音源の並び替え…」で一覧を開き、移動したい音源を選択します。「上へ」「下へ」「先頭へ」「末尾へ」、または移動先の番号を入力して「番へ移動」で順番を変え、「適用」で確定します。「キャンセル」なら元の順番を保ちます。
- 並び替え画面では`Alt+↑`／`Alt+↓`も使えます。複数列では一覧の順に左から右、次の行へ表示され、順番はプロジェクトへ保存されます。並び替えで再生や開いている詳細をリセットすることはありません。
- 音源一覧のホイールスクロールは短い補間で滑らかに移動します。スクロールバーのつまみはドラッグに即座に追従します。音量スライダーや数値欄の上でのホイール操作は、引き続きその値の調整に使用します。

名前、キー、Group、メモなどの入力は`Enter`またはカード内の余白クリックで確定し、`Esc`で編集前の値へ戻します。キー欄の空白は除去され、`A`、`2`、`F1`などとして解釈できない値は解除されます。

## キーボード操作とGroup

通常の割り当てキーで再生し、`Shift + 割り当てキー`で停止します。同じキーを複数音源へ割り当てると、対象を同時に操作できます。

Groupは音源の分類と一括操作に使います。排他再生ではないため、同じGroup内の音源も同時に再生できます。「操作」→「グループショートカット…」でGroup専用キーを登録すると、通常キーでGroup全体を再生し、`Shift + 登録キー`でまとめて停止できます。

`Alt + 音源の割り当てキー`は、その音源と同じGroupの他の音源を即時停止してから対象を再生します。Group専用キーには適用しません。同じGroup（Group未設定を含む）の複数音源に同じキーを割り当てた場合は、Alt操作の対象が曖昧になるため実行しません。通常の同時再生・一括操作は変わりません。

`Ctrl+R`、操作メニュー、画面上部の「全停止」は同じ全停止処理です。「全停止でも音源ごとのFade Outを使う」がOFFなら即時停止し、ONならFade Out設定のある音源をフェード後に停止します。「操作」→「ミュート」は、マスター音量下のミュートチェックと同じ状態を切り替えます。

バックグラウンド入力を有効にすると、別アプリを操作中でも割り当てキーを受け取ります。

`Ctrl+S`で保存、`Ctrl+Shift+S`で名前を付けて保存、`Ctrl+O`で開く、`Ctrl+N`で新規作成できます。設定・編集・ファイル選択・確認の各ダイアログを操作中は通常の音源キーを抑止します。

## 誤変更防止の編集ロック

本番中は、画面下の「編集ロック: OFF」を開いて「設定と音量をロック」を選ぶと、音源設定・音量・ミュート・出力先・イベントの編集や、音源の追加/削除/差し替え、並び替え、プロジェクトの新規作成/読込を防げます。「操作」メニューからも切り替えられます。開いていた速度・音程調整ウィンドウは閉じます。

ロック中も、音源とグループの再生・停止・一時停止・再開、通常全停止、緊急停止、自動イベントの明示再開、時計/SW操作、プロジェクト保存、一覧のスクロールは使えます。音源の「詳細」は確認できますが、値は変更できません。

解除するときは「編集ロック: ON」を開いて「編集ロックを解除」を選んでください。ボタン部分を1回押すだけでは解除されません。ロック状態はウィンドウタイトルにも表示されます。このロック自体はプロジェクトを書き換えず、再起動すると解除状態で始まります。出力先を変更・復旧するときも、まず編集ロックを解除してください。

## 音量、Pan、Loop、Fade

音量は通常0～100%です。音源の「詳細」→「速度・音程の調整…」で「音量の限界突破（上限200%）」をONにすると、その音源のメイン画面のスライダー・数値欄・音量フェードを200%まで使えます。ONにするだけでは音量は変わりません。MASTER音量の上限は100%です。

限界突破をOFFにすると、上限が100%へ戻ります。100%を超えていた音量は直ちに100%以内へ戻り、100%以下ならその値を維持します。再生中の音量フェードにも上限を適用します。調整画面の「標準に戻す」でも限界突破をOFFにします。数値欄の右クリックの「100%（標準）に戻す」は音量だけを戻し、限界突破の許可は維持します。

100%が元の音量、200%は振幅2倍の増幅です。音源や同時再生数によって音割れする場合があるため、出音を確認しながら調整してください。編集ロック中は限界突破の変更もできません。

限界突破の許可と音量は音源ごとに保存されます。従来のプロジェクトや許可設定のない音源は100%上限で開きます。未対応の旧版で開いて保存すると、増幅設定は100%へ丸められます。

- Panは`-100`が左、`0`が中央、`+100`が右です。Pan欄を右クリックすると中央へ戻ります。
- ループ開始秒は初回再生位置ではなく、音源末尾へ到達した次の周回で戻る位置です。
- Fade Inは次回の再生開始時に動作します。
- 通常停止時のFade Outと、全停止時のFade Outは設定画面で個別に切り替えられます。
- 全停止ボタンの「フェード／即時」は現在の設定を示します。一時停止中の音源は、フェードを待たずに停止します。
- 画面下の「緊急停止（即時）」または「操作」→「緊急強制停止（フェードなし）」は、設定に関係なく再生中・一時停止中・フェード中の全音源を即時停止します。準備中の再生も取り消し、出力バッファを停止します。確認画面は出ません。通常の全停止とCtrl+Rは従来どおりです。キー衝突を避けるため、緊急停止専用のキーは割り当てていません。自動イベントも休止し、「自動イベント再開」で復帰します。休止中も手動再生は可能です。SW計測は継続します。実行済みの条件や休止中に通過した時刻・SW条件を再開後に遡って実行することはありません。再開後に新しく成立した条件だけを実行します。0秒イベントはStartで1回だけ発火し、Pause/Resumeや緊急停止解除では再発火しません。SWのResetでSW条件を再び発火可能にします。
- Fadeを有効にしたとき秒数が0なら、1.00秒が自動設定されます。
- Fade Outを有効にして音量バーを右クリックすると、指定した音量まで設定秒数でフェードします。

「詳細」→「速度・音程の調整…」は、開いたままメイン画面で再生・停止できるウィンドウです。音源ごとに1枚ずつ複数開けます。音源削除・プロジェクト切替で閉じます。専用ウィンドウでは、再生を続けながら速度（0.50～2.00倍）、Pitch（0.50～2.00倍）、Panをスライダーで調整できます。横の数値欄からの入力も可能で、両方が連動します。速度を変えると音程も変わり、Pitchで別途音程を補正できます。「標準に戻す」で速度・Pitchを1.00、Panを中央へ戻します。スライダーを右クリックすると、その項目だけを標準値へ戻せます。変更はその場で音源設定へ反映され、プロジェクトに保存されます。Fade Inは次回再生時、Fade Outは次の停止操作で適用されます。

## イベントトリガ

次の条件から、音源単体またはGroup全体の再生・停止・一時停止を実行できます。

- 現在時刻
- ストップウォッチ経過時間
- 音源の再生終了
- 音源の再生経過時間

トリガは発火後も有効設定を維持し、同じ成立状態での連続発火だけを抑止します。ストップウォッチのリセットや音源の再再生で再び待機します。時刻トリガはアプリ起動後に指定時刻を通過した場合に発火し、起動前の時刻へ遡って発火しません。一覧のチェックボックスから有効／無効を切り替えられます。

音源の再生経過時間には一時停止中の時間を含めません。速度に関係なく、再生している実時間の秒数を数えます。参照先の音源・グループが見つからない場合は読込時に警告し、編集時は「不明」として表示します。別の音源へ自動で置き換えず、対象を明示的に選び直すまで確定できません。

## 表示と出力設定

設定画面では、出力デバイス、バックグラウンド入力、停止時Fade Out、ライト／ダークモード、音源一覧の列数などを変更できます。列数は1～8列で、ウィンドウ幅に収まらない場合は自動的に減ります。

ダークモードではタブの余白、ボタン枠、メニュー、入力欄も暗い配色に揃えます。Windows 11ではタイトルバーや標準スクロールバーにも暗い配色を適用し、ライトモードへ戻すときにも追従します。

設定した出力デバイスが消失・停止した場合は安全停止し、接続を確認して設定で出力先を選び直し、必要なら「自動イベント再開」を押してください。「Windows既定」は選択時の物理出力へ固定します。Windows既定の出力先・エンドポイントID・デバイス番号が変化した場合も停止し、接続が戻っただけでは自動復帰しません。既定出力を安全に識別できないドライバでは再生を保留するため、特定の出力デバイスを選択してください。列挙・確認はバックグラウンドで行います。確認は通常2秒間隔と再生直前であり、Windowsやドライバ内部の転送先変更を瞬時に保証するものではありません。実際の音響卓・ドライバで切断、既定変更、スリープ復帰を確認してください。

## プロジェクトと音声ファイル

プロジェクトは人が読めるJSON形式の`.pondex`ファイルです。同じフォルダまたは配下の音声は原則として相対パスで保存されます。別PCへ移す場合は、`.pondex`と音声ファイルの位置関係を保ったままフォルダごとコピーしてください。

安全上、プロジェクトと音源にUNCパス（`\\server\share`）、Windowsデバイスパス、ネットワークドライブは使用できません。ジャンクションやシンボリックリンクは実体のパスで判定します。プロジェクトフォルダ外のローカル音源、バックグラウンド入力、または有効なイベントトリガを含むプロジェクトを開く際は確認画面が表示されます。信頼できない入手元のプロジェクトは開かないでください。

読み込み時の上限は次のとおりです。

- プロジェクトJSON（`.pondex`）: 8 MiB
- 登録音源: 500件
- グループショートカット: 500件
- イベントトリガ: 1,000件

8 MiB制限は設定JSONだけが対象です。WAVやFLACなど、音声ファイル本体の容量は制限しません。

読込時に復元できなかった項目がある場合、元ファイルへの上書きを拒否します。別の名前で回復用のコピーを保存してください。欠落音源は名前とパスを通知し、登録を保持します。

保存時は一時ファイルを検証してから置き換え、既存プロジェクトがある場合は`.pondex.bak`を作成します。旧「効果音ポンだしくん」のプロジェクト形式は直接読み込めません。

保存用一時ファイルには毎回異なる名前を使い、既存の同名ファイルは上書きしません。保存中の変更が残っている場合は未保存状態を維持し、保存完了を理由とする終了・プロジェクト切替を中止します。もう一度保存してから操作してください。

本体の保存に成功しても、バックアップの整理だけが失敗する場合があります。この場合は保存成功として扱い、ステータスとログに復旧用バックアップの場所を表示します。既存の`.bak`と直前の内容を別々に保持するので、復旧用ファイルは内容を確認するまで消さないでください。

## 動作診断とログ

「操作」→「動作診断…」では、対応音声形式、Pitch＋Loop、Fade、無音ループ、バックグラウンド入力、DPIモードを確認します。診断中は短いテスト音が鳴ります。

「設定」→「診断ログ」の「詳細ログを記録」をONにしてOKを押すと、すぐに詳細記録を開始します。既定はOFFです。再生要求、音源ファイルのパス・音量・Pitchなどの設定、準備時間、再生・一時停止・再開・停止理由、出力先、ショートカットで実行した操作、イベント発火、プロジェクト操作を`[DEBUG]`行に記録します。設定はプロジェクトに保存され、再び開いたときにも反映されます。OFFに戻すと追加の詳細記録を停止し、通常の情報・警告・エラーは引き続き記録します。

ログはアプリ起動中も随時ファイルへ反映します。音声コールバックからのファイル書き込みは行わず、書き込みが追いつかない場合はDEBUG、INFO、WARN、ERRORの順で優先的に破棄します。低いレベルのログで高いレベルのログを押し出すことはありませんが、ERRORだけで上限に達した場合は古いERRORも失われる可能性があります。破棄数は`ログ破棄（累計）`の行とロガーの診断情報で確認できます。ファイルは各ログの記録日時に従い日ごとに切り替わります。保存先が消失・故障した場合はログ機能を停止し、音声処理を継続します。詳細ログにはファイルパスなどが含まれるため、共有前に内容を確認してください。

「操作」→「再生開始時間をログに記録」は必要な間だけONにします。`prepare_ms`はPlay要求からデコーダのオープン・再生パイプライン準備完了まで、`start_ms`は出力の再生開始処理までの累計時間です。ファイル全体のデコード完了ではありません。`attempt=1`は計測をONにしてからその音源を初めて準備した要求、2以降は再度の要求です。OSのキャッシュ状態を制御するものではなく、毎回再生用インスタンスを準備します。最新128件を内部保持し、計測OFF時は追加計測・計測ログを行いません。

この数値にデバイスバッファ・ドライバ・スピーカーの遅延は含まれず、実際の出音遅延ではありません。出音の検証は対象機器で別途行ってください。

GUIを開かずに診断する場合:

```powershell
PondashiEX.exe --audio-self-test
```

長時間運転診断を120分実行する例:

```powershell
PondashiEX.exe --soak-test-minutes=120
```

ログは実行フォルダの`Logs/`、最近使ったプロジェクト履歴は`Data/recent-projects.json`へ保存します。アプリフォルダをコピーすればこれらも移せます。アプリフォルダ内のプロジェクトは履歴も相対パスになり、ドライブ文字が変わっても参照できます。表示・出力などの設定は従来どおり各`.pondex`に保存します。音源は自動で同梱しないため、プロジェクトと音源フォルダも相対配置を保ってコピーしてください。

書き込めない場合は`%LOCALAPPDATA%\PondashiEX`、そこにも書き込めなければ一時フォルダへ退避します。すべて書き込み不可でも、ログを無効にして起動を継続します。旧ユーザーフォルダの履歴は新しい履歴がない場合に読み込み、次の履歴保存で移行します。旧ファイルは削除しません。ユーザーフォルダ・一時フォルダへの退避分はアプリフォルダのコピーに含まれません。

本番利用前には、実際に使うPC、音声デバイス、音源で動作診断と通し確認を行ってください。

アプリ内でも「ヘルプ」→「使い方…」から主要機能の説明を確認できます。
